# Clarté Overseas — Website

Marketing/B2B site for **Clarté Overseas**, an India-based merchant exporter of
dehydrated fruits, vegetables, flakes & powders. Built with **Astro** (static
output) + **Tailwind CSS**, deployed on **Vercel**.

## Requirements
- **Node 18+** (this repo is developed on Node 22 via nvm). Astro will not run on Node 14/16.
  ```bash
  nvm use 22   # or: nvm install 22
  ```

## Commands
```bash
npm install        # install dependencies
npm run dev        # local dev server → http://localhost:4321
npm run build      # production build → ./dist
npm run preview    # preview the production build
```

## Project structure
```
src/
  pages/         file-based routing → URL (index.astro = "/"; about.astro = "/about")
  layouts/       BaseLayout.astro — <head>, SEO/OG, analytics, Navbar + Footer wrapper
  components/    Navbar.astro, Footer.astro, Analytics.astro
  consts.ts      ⭐ central config: site URL, analytics IDs, contact, social, Formspree
public/          static assets served at site root
  assets/        logos & images        css/styles.css        js/script.js
  robots.txt
astro.config.mjs   site URL + integrations (tailwind, sitemap)
tailwind.config.mjs brand tokens (colors, fonts)
```

## Clean URLs
`build.format: "directory"` + Vercel → pages serve **without `.html`** (e.g. `/about-us`).
New page = new file in `src/pages/` (e.g. `src/pages/about.astro` → `/about`).

## SEO / indexing
- Per-page `<title>`, meta description, canonical, Open Graph & Twitter tags (via BaseLayout props).
- Organization JSON-LD in BaseLayout; add Product/Article schema per page as we build.
- `sitemap-index.xml` auto-generated by `@astrojs/sitemap`; `robots.txt` references it.
- On migration: add 301 redirects (vercel.json) from old GlobalLinker URLs → new URLs.

## Versioning
Git history is the rollback mechanism — each change set is committed before/after edits.
`dist/`, `node_modules/`, `.astro/` are gitignored; `package-lock.json` IS committed
(Vercel installs exact locked versions, incl. `@astrojs/sitemap@3.2.1` pinned for Astro 4).
